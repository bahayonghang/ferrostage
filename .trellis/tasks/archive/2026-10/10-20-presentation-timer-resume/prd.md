# 演示计时续接与顶栏计时器重设计

## 背景

演示者视图中，`Esc`（`stop_presentation`）、底部“结束演示”、显示器丢失导致的安全停止，都会让会话从 `Presenting` 回到 `Ready`。core 在 `StopPresentation` 时已冻结计时（`TimerState::pause`），但再次点击“开始演示”会调用 `TimerState::start` 把用时清零。答辩、讲座中途误按 `Esc` 后重新开始，前面的用时就丢了，演讲者无法按原节奏控制时间。

同时，顶栏计时器只是一行“已用时 00:00”文字，挤在标题和右侧操作之间，位置随文件名长度漂移，不够醒目；“布局与导航”在底部工具栏最右侧，与其它文档级管理操作（返回首页、打开 PDF、设置、显示器设置）分处两地。

## 目标

1. 中途结束演示后，计时冻结、不归零，演讲者可选择**继续演示（计时接着走）**或**重新开始（计时归零）**。
2. 顶栏计时器重新设计，并在顶栏水平居中。
3. “布局与导航”移到顶栏右侧操作区。

## 需求

### R1 可续接的已停止会话

- 进入 `Presenting` 后计时开始走。
- 从 `Presenting` 退出到 `Ready`（`Esc`、结束演示按钮、无可用观众屏导致的安全停止）且本次已用时 ≥ 1 秒时，形成“可续接会话”：计时冻结在退出时刻，顶栏数字不再变化。
- 可续接会话在以下情况失效并清零：打开另一个 PDF、返回首页（关闭文档）、选择“重新开始”。
- 同一 PDF 的外部热重载（`CommitDocument`）保留可续接会话和冻结值。
- 当前页码在继续或重新开始时都保持不变（沿用现状：开始演示不改页）。

### R2 左下分体按钮

- `Ready` 且无可续接会话：保持现有单个“▶ 开始演示”按钮，外观与行为不变。
- `Ready` 且有可续接会话：该位置变为一组两段按钮：
  - 主段“继续演示”，副文本显示将要续接的时间（如“从 12:34 继续”）；点击后进入 `Presenting`，计时从冻结值接着走。
  - 次段“重新开始”，副文本“计时归零”；点击后进入 `Presenting`，计时从 00:00 开始。
- `Presenting`：保持现有“结束演示”按钮。
- 两段共享禁用原因提示、“正在准备…”忙碌态、防重复触发；忙碌时只有被点的那一段显示“正在准备…”，另一段禁用。
- 演示方式下拉（双屏 · 标准 / 讲稿优先 / 单屏）仍在分体按钮右侧，对两种启动都生效。
- 键盘：`start_presentation` 快捷键（默认 `F5`）在有可续接会话时执行“继续演示”，没有时执行“开始演示”。“重新开始”只通过按钮（鼠标或 Tab 焦点 + Enter/Space）触发，避免误归零。不新增快捷键设置项。

### R3 计时器视觉重设计与居中

- 计时器在顶栏中水平居中（相对窗口宽度），左右两侧内容不挤动它，直到某侧真的放不下。
- 计时器状态必须可区分且不只靠颜色：计时中、已暂停、已停止（可续接）、未开始、黄/红阈值告警。
- 数字使用等宽字体，数位与状态切换不导致数字水平跳动。
- `Presenting` 时暂停/继续计时、重置计时操作仍可直接访问。
- 不加入闪烁或作为唯一信号的动画。

### R4 “布局与导航”移至顶栏右侧

- 从底部工具栏移除“布局与导航”触发器，放到顶栏右侧操作区，`Ready` 和 `Presenting` 都直接可见。
- 菜单改为向下展开、右对齐，内容和交互（自动 / 不拆分、识别独立讲稿页，键盘导航、Esc / 外部点击关闭并还原焦点）不变。

## 约束

- `ferrostage-core` 仍不依赖 GPUI / PDFium / lopdf / notify；计时逻辑只用注入的单调时钟。
- `AudienceProjectionSnapshot` 不变，观众窗口不感知续接状态和计时器。
- 不新增 settings 键；不改 `settings.toml` schema。
- 先改 `DESIGN.md`（计时器、顶栏、分体按钮、布局与导航菜单相关条目），再改 token 层和视图。
- 中英文文案同步（`assets/locales/{zh-CN,en-US}/app.toml`）。

## 验收标准

- [ ] core 单测：Stop 后可续接；`ResumePresentation` 从冻结值继续；Start/重新开始归零；Load/Close 清除可续接；热重载保留；Stop 时用时 < 1 秒不可续接；非法阶段调用返回 `NotReady` 且状态不变；属性测试涵盖新命令。
- [ ] UI 测试：`Ready` + 可续接时出现两段按钮且分别派发 Resume / Restart；无可续接时只有单按钮；`F5` 在两种状态下派发正确意图；Presenting 时顶栏可见“布局与导航”，底部工具栏不再有该触发器；菜单向下展开且焦点还原。
- [ ] 计时器在宽窗口（≥1280）、中等（800–1279）下居中，文件名超长时数字不移动；窄窗口（<800）仍可见且不截断。
- [ ] 计时器各状态在明暗主题下对比度满足 DESIGN.md 要求（正文 ≥4.5:1，UI/焦点 ≥3:1）。
- [ ] `just ci` 通过。
- [ ] 原生手动验收：开始 → 走几秒 → `Esc` → 顶栏冻结 → 继续演示接着走；再次 `Esc` → 重新开始归零。明暗主题截图各一组。
