## I-1 decisions to make concrete

Keep native link-time dependencies out of the GUI graph, including through Cargo feature unification. A separate helper executable/package with its own required native feature is a feasible structure; the GUI's media feature should reach only the safe controller/protocol and pure animation decoder. Default workspace CI must stay usable without the native SDK/runtime, while explicit native build/lint/tests exercise the real helper.

Distinguish pure animation and native video/audio capability: missing GStreamer must not disable PDF controls or the independent GIF/WebP decoder. Media-enabled missing-runtime tests should exercise that distinction. Ready never starts audio even on a media click; expose the relevant unavailable/not-presenting state in Presenter controls without publishing diagnostics to Audience.

Use bounded framed IPC with explicit identity and checked geometry/length. Parent always drains the helper pipe on a background thread and retains a bounded latest-frame queue; do not let UI stalls create unbounded raw-frame allocations or block stop commands. Native control/stop should not wait on a blocking UI-thread write/read/join. A helper crash/EOF produces a typed slot failure, preserves the PDF and cannot silently spawn a second audio owner. Explicit stop acknowledgement and bounded child termination must also cover parent shutdown and stale generation/epoch frames.

Require one audio owner and deterministic source selection. Source resolution, embedded materialization in app-owned temporary artifacts, codec diagnostics and progress stay on the Presenter/controller side. Audience receives only the existing pure slot/rect/pixels shape, behind generation/page/epoch filtering in the assembler. Shared BgraFrame ownership and08 texture guards must cover media as well as PDF rasters. Notes/source paths must never enter the snapshot.

Integrate task10's final generation-invalidation path once it exists; do not invent a parallel reload owner. Ready, page departure, blank, Stop, Close and generation changes invalidate playback immediately; delayed helper/animation frames cannot resume it. Preserve explicit restart semantics after leaving blank. Complete source metadata consumers (autostart, activation, start, duration, repeat), full UI controls and settings consumers rather than reporting decoder-only completion.

Bound animation allocation before collecting frames: source dimensions/decoder limits, checked per-frame geometry, cumulative frame bytes and duration validation all matter even when output is downscaled. For native frames, preserve aspect ratio within configured height and1920 width; reject malformed IPC dimensions/length before allocating. `MediaSlot.slide_rect` currently contains the destination intersection with the selected slide crop. If an annotation straddles that crop, preserve the corresponding source-pixel crop as well; squeezing its entire image into the destination intersection would distort/retain private-region content. Compute this on the controller side and publish only the authorized public pixels/rectangle. Select playable slots only from the current content page with a nonempty public intersection: an annotation wholly inside a private notes region must not autostart an invisible video or its audio. Test both a straddling rectangle and a notes-only rectangle; a normal public audio-only slot still plays through the single audio owner.
