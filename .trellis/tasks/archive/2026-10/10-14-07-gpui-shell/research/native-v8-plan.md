# V8 native acceptance plan

Root exclusively controls the native desktop through the computer-use skill. This is a planned matrix; no V8 native PASS is claimed. All screenshots/logs/configs are NEW v8 artifacts. Historical V6/V7 remain intact. Freeze source/exe/DLL/fixture identity after serial implement/check; run one owned application at a time and verify exit before relaunch. Use isolated task-owned configurations and real user-facing controls.

1. Startup, replacement and actual title-bar close: retain source-attributed logs; reject unexplained window-not-found/invalid-handle/dispatcher errors separately from exit code.
2. Ready display entry opens without moving/saving. Count and numbered monitor rows match Identify physical overlays and current topology. Capture list and overlays with identical numbering. Identify expires after3s.
3. Draft application/PDF selection with Cancel: read back identical config hash and unchanged effective window placement; keyboard traversal and returned focus remain usable. Reject same-screen multi-display conflict.
4. Apply B application/A PDF and B application/C PDF using the new controls. Ready remains Ready/no audience; Start creates only chosen audience; Stop removes it. Read MonitorId roles from task config. Relaunch restores assignments. No old Swap/config receipts substitute for this.
5. Presenting valid migration preserves page/stage/timer; Identify disabled. Selecting no-play curtains/stops/closes audience, keeps committed page, freezes timer and disables Start. Read settings mode as presenter_only.
6. Isolated actual file read-lock: Apply runtime role change succeeds, single unsaved message; Retry while locked fails, after unlock saves and clears feedback; config read-back and restart. Future-version isolated config stays read-only.
7. Light/dark and supported native logical sizes; validate viewport from V7 diagnostics, not screenshot outer geometry. Check Tab/ShiftTab/Enter/Space/Escape, focus restoration, long labels, scrolling and actual placement. Reuse unchanged historical observations only with explicit identity limits.
8. Remaining nonphysical07 checks where possible: real file drop, audience key/cursor behavior, Curtain capture, live OS theme event. Unsupported or unobservable behavior stays NOT_RUN/UNVERIFIED with reason; never infer PASS from build/simulation.

Physical unplug/reconnect/connector/identity-latency and true single/zero-display hardware are excluded from this turn by user request and remain NOT_RUN. Their gate implications remain. Gate B cannot pass by lowering thresholds;08–11 wait on dependencies.
