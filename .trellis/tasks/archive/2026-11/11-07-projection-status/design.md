# 真实投影状态与绘制回执的实现边界

讲者侧并列保存配置目标、观众窗口实测 MonitorId、请求目标及最后完成绘制的公开身份。复用既有 PlaybackIdentity 和 Settled。不能用 CPU 光栅或新快照发布冒充绘制；关闭/替换窗口时撤销该窗口的回执资格。保持定时步进订阅的语义。

## 已核对的现有入口

- `shell/timed_playback.rs::select_playback` 已为普通 PDF 和带播放元数据的文稿分配身份；不需要再建一套导航序号。
- `playback_event` 已验证当前观众窗口、代数、导航、快照以及重载/放置事务；在同一通过校验的边界记录 Settled，避免状态条绕过既有门禁。
- `audience/playback.rs::painted` 的延迟通知仅在仍然 Live、未遮屏、身份一致时交付。保留 FirstVisible 与 Settled 的区别，不提前消费通知。
- `display_settings::observed_location` 从实测 GPUI display 和稳定 MonitorId 映射位置。复用它及现有显示器标签；请求的 `WindowRecord.monitor` 不能充当实际位置。

## 状态与 UI

只增加讲者会话的最后已绘制身份和必要的观众窗口来源。顶部展示未开始/准备中/已绘制与待切换、实际位置或未知；详情使用既有显示器入口。就绪态展示配置目标。正常翻页等待完整目标页 Settled 后更新，失败保留最后已绘制页并显示现有失败原因。原生窗口替换后不能沿用旧窗口的绘制事实。

黑/白遮屏状态独立于最后已绘制页，并提供显式恢复动作。恢复只清除遮屏；不改变计时、画笔或自动播放的显式暂停。遮屏下选定的底层目标仍可准备，但不伪造可见绘制回执。后续返回位置任务可读取这个精确就绪条件，不能将它标成已投出。

## 集成与回退

状态条只读既有事实，不能触发额外导航，不修改观众快照的隐私边界。撤回 UI 和会话记录即可回到现有播放流程。单屏全屏观众端不接收讲者状态条。

## 验证边界

GPUI 回归覆盖普通页、转场结束、旧窗口/旧代/旧导航、保留旧帧、失败、遮屏恢复及显示器未知。普通原生窗口记录真实位置与应用绘制日志；没有物理投影仪证据时不声称外部设备已经显示。原有计时/显示器回归只跑直接受影响项。
