# 讲者界面轻盈毛玻璃与外观设置

## 目标

把整个讲者界面换为 design-atlas 的轻盈毛玻璃。用户能独立选择明暗和材质，保存后下次打开仍生效。

## 当前依据

根 DESIGN.md 定义暖色 Claude 风格；`crates/ferrostage-ui/src/theme.rs` 管理色板、按钮和字体；`GeneralSettings` 已有 light／dark／system，当前新配置默认 dark。用户已明确保留三个模式并另设开关。

## 验收条件

- [x] 首页、就绪／放映工作台、设置、浏览／跳转、布局菜单和对话面板共享新色板、字形、圆角与按钮状态。浅色薄荷→淡紫底场、白纸面、绿色操作与紫色输出；深色提供同系深底及 AA 对比，关闭效果也保留新风格。
- [x] 设置提供浅色／深色／跟随系统和独立「毛玻璃」开关。按现有设置应用模型刷新当前讲者界面，重启后保留。旧配置保留明暗值，并给缺失的效果字段明确默认；无效值走现有警告与回退。
- [x] 开启且环境支持时才启用模糊；关闭、窄窗、减少透明度或能力不足时用同色实色表面。向用户区分材质偏好与实际回退。以开启和关闭同一场景的原生截图验证实际差异。
- [x] 按钮有可辨认的默认、悬停、按下、禁用、选中与键盘焦点。正文对比 ≥4.5:1，边界／焦点 ≥3:1；用实测深色与合成后的最差背景验证。界面缩放、字体覆盖继续有效。
- [x] 主题即时切换不改投影页、遮屏、计时、PDF／私有备注图像及其原始色彩。测试真实设置入口和重启回读，记录普通窗口截图与键盘复核。
