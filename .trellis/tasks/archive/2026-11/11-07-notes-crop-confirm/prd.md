# 同页备注裁切预览与放映前确认

## 目标

让讲者在创建观众窗口前看到真正要投出的像素，并能纠正备注方向。

## 当前依据

改动前新文稿默认整页，菜单提供自动与不拆分，底层已支持四方向等分。已用受控双色 PDF 在旧版原生观众窗复现：公开区和私有区同时出现。[基线像素](research/native/baseline.json)

## 验收条件

- [x] 普通 PDF 与正确配对的独立备注沿用原 Start；页面尺寸一致且命中现有双联候选规则时，在首次 Start 前展示确认。混合尺寸不猜方向，任何文稿在 Ready 均可手动检查。
- [x] 面板显示「观众可见／仅讲者可见」两幅真实预览，可切换样本并用键盘选择整页或左、右、上、下。独立备注仍按原映射展示。样本翻页不改主讲述页；加载中或失败不能确认。
- [x] 菜单确认后留在 Ready；Start 入口确认才开始。取消／Esc 不开观众窗；原规则不重建，不清批注。改变裁切前提示会清批注，成功才提交；失败保留计时、批注、页与规则。
- [x] 本次打开内 Stop／Resume 复用确认，重新打开重判。放映中只读；热重载几何、旋转、映射、页数或裁切变化时保留旧版，停止后重新确认；同结构沿用确认。
