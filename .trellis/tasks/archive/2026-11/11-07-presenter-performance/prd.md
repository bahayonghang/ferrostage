# PDF 打开与 Beamer 放映卡顿诊断及优化

## 用户目标

缩短打开文稿后看到可用预览的等待，减少现场逐步翻页时观众看到旧页或迟滞的时间。诊断覆盖仓库的 100 页真实 Beamer 夹具与 overlay 文稿。已有局部基线和待验证假设见[初步诊断](research/findings.md)。

## 验收条件

- [x] 用相同 release 构建条件、机器、输入 SHA、分辨率、缓存预算和操作序列记录改动前后数据。分别计量应用接受打开到首张讲者 PDF 成功绘制、开始到观众首张、翻步输入到对应公开目标 FirstVisible，以及带转场的 Settled。
- [x] 分开报告首次打开和同文件重开、已缓存和未缓存、连续前进／回退和快速连按。给出样本数、原始数据、中位数、P95、超时、丢弃或合并请求数；OS Present 未采集时只标应用绘制边界。
- [x] 针对能复现的主瓶颈做最小改动，记录等待、光栅次数或复制字节如何改变，并在相同路径重复 A/B 测量。至少一个受影响的用户路径改善大于同版本复测波动；另一路径无可重复的退化。没有观察到收益的候选改动撤回。
- [x] 保持 PDFium 单渲染线程、原 BGRA8 与画质、L1/L2 预算、只读 PDF 和候选提交语义。逐步顺序、备注隔离、旧帧保留、遮屏、reload 代数、转场与自动步进不退化。未实际观察的设备或 OS 指标单独标记。
- [x] 按同一套场景运行相关自动回归和一次普通原生窗口验证；最终报告指出已改善哪一段、仍慢的是哪一段、其他样本的外推限制。

## 范围

本项聚焦打开 PDF 与现场放映。主题开关可以作为后续集成对照，先固定外观以免干扰基线。暂不扩展编译器、编辑器、通用性能仪表板或全平台设备矩阵。
