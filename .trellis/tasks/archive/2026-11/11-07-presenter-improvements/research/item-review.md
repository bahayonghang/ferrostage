# 引用聊天逐项核对

来源为本地聊天 `01a1b4d7-9da9-7de3-b4cc-e41e9ae541c5` 的两轮分析（2026-11-07）。第一轮比较 TeXora 和当前 FerroStage，第二轮给出了四项详细方案。用户本轮明确更换旧视觉，随后选定保留明暗三选一并另设毛玻璃开关。以下结论按当前工作树核对；原生行为、性能和导出器兼容率均待实际验证。

| 建议 | 当前依据、决策和可验收结果 |
|---|---|
| 打开、双屏、翻页笔、计时、批注、热重载、转场及媒体 | 已有对应入口和状态机。保留作为相关回归，避免把已归档的工作重新立项。 |
| 同页／独立备注与四向纠错 | **首轮 P0**，底层已有方向裁切，默认整页可能连备注像素一起显示。新增预览确认；普通宽屏可按整页开始。 |
| 投影状态 | **首轮 P0**。显示已绘制身份与实测 MonitorId，区分待绘制、遮屏、失败和失联。实际窗口不等于物理投影仪。 |
| 一次跳转后返回 | **首轮 P1**。保留第一次离开的准确步骤，直接跳转入口保持现状；停止再续讲可返回，文稿换代后失效。 |
| 无备注空间、下一步与比例复位 | **首轮 P1**。按全稿判定；末页、加载或部分页无备注时不跳动。保留双屏与现有讲稿优先布局。 |
| 整体配色、按钮与外观 | **本轮新增**。上一轮“保留暖中性色”的建议已由用户替换。仅讲者界面采用轻盈毛玻璃，设置支持明暗三选一和独立材质开关。 |

| 浏览大图、章节分区、按逻辑页分组缩略图 | 后续。面板候选预览不能移动投影；保留当前缩略图／目录点击即跳转的契约，为私有预览提供显式入口。 |
