# 放映可靠性、临场导航与讲者界面优化

## 目标

让讲者在开始放映前确认哪些像素对观众公开，演示时知道已输出的页，临场答疑后能返回原步骤。把普通无备注 PDF 的讲者空间还给预览，并将整个讲者界面换为可配置的轻盈毛玻璃。

## 首轮任务

- [同页备注裁切预览与放映前确认](../11-07-notes-crop-confirm/prd.md) — 让讲者在创建观众窗口前看到真正要投出的像素，并能纠正备注方向。
- [真实投影状态与绘制回执](../11-07-projection-status/prd.md) — 让讲者不用打开设置就能确认观众窗的位置、已经输出的页及黑白遮屏。
- [答疑跳转后返回准确讲述步骤](../11-07-return-position/prd.md) — 讲者连续跳到多个附录或补充页后，可以一次返回跳出前的幻灯片和 overlay 步骤。
- [无备注文稿的稳定双预览布局](../11-07-notes-free-layout/prd.md) — 整本文稿没有备注时把可用空间交给当前页和下一步；同一份混合文稿翻页时保持工作区稳定。
- [讲者界面轻盈毛玻璃与外观设置](../archive/2026-11/11-07-presenter-airy-glass/prd.md) — 把整个讲者界面换为 design-atlas 的轻盈毛玻璃。用户能独立选择明暗和材质，保存后下次打开仍生效。
- [PDF 打开与 Beamer 放映性能](../archive/2026-11/11-07-presenter-performance/prd.md) — 建立首张预览和输入到观众绘制的基线，优化能复现的卡顿并复测。

## 集成验收

- [ ] 普通文稿直接开始，有疑点的文稿可预览再确认；取消后没有观众窗。公开像素与输入 PDF 字节校验通过。
- [ ] 第一次从步骤 2 跳至附录、再跳到另一页时，仍能按已绘制结果返回步骤 2。遮屏、计时和批注遵守原规则。
- [ ] 无备注文稿双预览、有备注文稿保留布局；开关材质和切换明暗不会使 PDF、备注或观众画面染色。
- [x] 性能改动以同机、同文稿和同画面尺寸的前后数据验收，分别记录打开和放映路径。
- [ ] 六个子项分别验证直接受影响的状态路径；集成运行 `just check-shell`、`just ci` 并记录普通原生窗口结果。编译或自动化测试不能代替原生界面验收。
