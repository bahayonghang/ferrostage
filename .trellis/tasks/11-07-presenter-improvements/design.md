# 任务边界与依赖

文档层给出已解析备注结构和公开裁切区域；讲者 shell 管理预览、确认、导航和显示器观察；core 保持不依赖 UI、PDF 解析或文件观察。观众只读 AudienceProjectionSnapshot，向讲者回报已绘制的公开身份。外观设置经过现有 settings 事务进入讲者 theme.rs。

裁切确认提供“待确认／有备注／确认无备注”的文稿事实，供无备注布局使用。投影状态提供成功绘制或底层公开帧就绪的依据，供返回任务在正确时刻消费位置。外观任务可独立推进，将新控件复用到后续四项；各项均有自己的 PRD 和实施清单。局部失败保留正在工作的旧画面、旧文稿或旧设置。
