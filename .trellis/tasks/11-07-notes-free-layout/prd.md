# 无备注文稿的稳定双预览布局

## 目标

整本文稿没有备注时把可用空间交给当前页和下一步；同一份混合文稿翻页时保持工作区稳定。

## 当前依据

`presenter/workbench_view.rs::workbench_panel` 构造备注区，`workbench.rs::requests` 按步骤请求预览。当前页没有备注纹理可能由未加载、失败或局部缺页导致。

## 验收条件

- [ ] 整本无备注时仅显示当前页／下一步。宽窗以 70:30 起步，右侧最小 240 逻辑像素；既有 800 断点以下上下排列，预览完整容纳。末页保留下一步位置并显示结束提示。
- [ ] 同页备注待确认、有独立备注或仅部分页有备注时保持既有布局；区分本页无备注、加载和失败。翻过空备注封面时面板不伸缩。
- [ ] 无备注比例拖动只在本次文稿会话生效；菜单恢复对应布局默认比例。有备注文稿恢复其保存的标准／讲稿优先比例。
- [ ] 布局、拖动、恢复不改变输出页、显示器分配、计时或批注；普通与双屏两种工作台模式都可使用。
