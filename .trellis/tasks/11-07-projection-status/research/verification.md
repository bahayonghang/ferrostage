# Projection status verification

## Result and boundaries

The presenter status separates the selected target from the last fully painted public identity. Ordinary PDF pages use the same receipt path as transitions. Actual location comes from the existing observed display/MonitorId mapping; requested location remains a configured target. Black/white state has an explicit Restore action. No status state is added to the core audience snapshot or drawn on the audience window.

`settled_playback()` retains accepted historical paint only for the current stage, generation and audience window. `public_frame_ready()` is a separate exact-current readiness condition that rejects loading, placement, graphics diagnostics and reload/recovery blocks; covered readiness is never called a visible paint receipt.

The regression failed before the minimal fix and passed after removing only that extra rejection. Audience still rejects painting while covered; Shell retains its source, generation/navigation, session, placement/reload and snapshot identity guards. The test also verifies zero-dwell navigation remains live after unblank. Eleven focused related regressions and the final full suite passed.

Coverage includes retained old page during pending/failure, FirstVisible versus Settled, actual plain-page Audience paint, wrong window/generation/navigation, covered paint, failed-worker readiness/warning, unknown/configured placement, blank Restore and timer/autoplay-pause preservation. The status received an explicit accessible name because GPUI does not infer one from text children. Output-problem copy remains generic because a successful transition fallback can also carry a diagnostic.
