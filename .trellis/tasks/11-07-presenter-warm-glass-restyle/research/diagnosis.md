# 现状诊断：为什么"轻盈毛玻璃"没有毛玻璃感

依据：用户截图 [深色工作台](before/dark-workbench.png)、[深色首页](before/dark-home.png)；设计源 `design-atlas show style:airy-glass` 与根 `DESIGN.md`；代码 `crates/ferrostage-ui/src/theme.rs`、`presenter.rs`、`presenter/material.rs`、`presenter/workbench_view.rs`、`presenter/home_view.rs`。

## 原始设计的"感觉"从哪里来

design-atlas 的 `style:airy-glass` 的轻盈感来自四件事：

1. **明亮低饱和的底场**（薄荷→淡紫 160°）和最多 3 个柔和色斑。
2. **一张白纸**：0.78 白、模糊 20px、一道几乎看不见的白色亮边（`rgba(255,255,255,0.80)`）、一层淡阴影 `0 20px 48px rgba(70,90,120,.08)`。
3. **大圆角 + 留白**，按钮和标签是 pill，**边界靠填充，不靠描边**。
4. 原规范明写 "No dark theme"、"亮边不是控件边界、不是不透明围栏"、"不要叠阴影或发光"。

## 实现偏离点（按视觉影响排序）

### D1 窗口外圈：底场 + 整窗纸 + 不透明亮边（用户问题 2）

- `presenter.rs:1302-1327`：根节点铺底场渐变，再 `p(inset)`，空闲首页 inset = 24px，工作台 8px；随后 `material.paper(p, inset)` 在整个窗口上绝对定位一张纸，四周留出 inset 宽的底场带。
- `material.rs:93-110`：纸带 `border_1()` + `sheet_edge.alpha(0.80)`。深色 `sheet_edge = #A3B9B1`（`theme.rs:215`）是不透明的浅灰绿，因此变成一圈清晰的浅色围栏线，正好违反原规范"亮边不是不透明围栏"。
- Windows 下 `Native` 时底场只有 0.75 不透明度（`FIELD_ALPHA`），窗口背后的桌面颜色从这条 24px 带透出来（截图底部的紫色/杂色），与深绿纸面色相不连贯。
- 网页里"纸浮在场上"成立，是因为页面比纸大。原生桌面窗口本身就是边界：再缩进一圈、画一道线，看起来就是"窗中窗"，加上系统黑色标题栏，就成了截图中格格不入的外圈。

### D2 三个互相打架的色相（用户问题 1）

- 主操作、焦点、选中、导航按钮、成功都是绿（深色 `#83DFB7`，浅色 `#187A56`）。
- 输出、计时胶囊、讲稿面板底色是紫（深色 `card = #312C44`，`output = #C6B4FF`）。
- 深色纸面 `#172321`、`soft = #213A32` 带青绿底色。
- 截图中同屏出现：绿色"开始演示"、绿描边按钮、紫色计时胶囊、紫色讲稿面板、青灰纸面、黑色标题栏、纯黑讲稿内框——没有一个主色。原设计里"绿=输入、紫=输出"在演示软件中没有对应的语义，只剩装饰。

### D3 每个按钮都有描边，导航按钮额外刷绿（用户问题 3）

- `theme.rs:146-185` `Palette::button`：默认样式 `border = self.border`；`presenter.rs:661-662` 对每个按钮面都 `border_1()`。结果是所有 pill 都带一圈 `#859D94` 线。
- `Navigation`（上一页/下一页/布局与导航/开始模式）填 `soft`（绿色洗底）+ 绿色文字；选中态再加绿边。
- `workbench_view.rs:1071-1098`：黑屏/白屏组、激光笔/画笔/荧光笔/橡皮组外面又包一层 `rounded(16).bg(p.soft)` 绿色底，里面的按钮仍各自是带描边的 pill；外壳半径 16、内部 pill 999，两种形状叠在一起。这就是"强行包裹了一层绿色"。
- 选中态在文字前加 `✓ `（`presenter.rs:610-614`），会让按钮宽度跳动。
- 根因之一是测试 `theme.rs:299` `semantic_button_states_keep_text_and_boundaries_readable`，它要求 Utility/Primary/Destructive 和禁用态的描边对 canvas ≥3:1，把"每个按钮都要描边"固化成了约束。WCAG 2.2 SC 1.4.11 只要求"识别控件所需的视觉信息"达到 3:1；带文字标签的按钮靠文字即可识别，不需要描边。真正必须 ≥3:1 的是焦点指示器与选中状态标记。

### D4 面板层次混乱

- 讲稿面板：紫色 `card` 外框 + 内部近黑的讲稿区，两层颜色都和纸面无关。
- 当前页/下一页预览没有容器，标题直接落在纸上；讲稿面板却有容器，左右不对称。
- 顶栏和底栏只有一条 `p.border` 横线分隔，没有材质层次。

### D5 字体（非本任务缺陷）

截图中的衬线字形来自用户自己的设置 `ui_font_family = "WenYuan Serif SC"`（`%APPDATA%/ferrostage/settings.toml:48`），不是回退错误。本任务保留字体覆盖行为；验收截图同时用默认字体和该覆盖各拍一组，确认新样式在两种字形下都成立。

## GPUI 能力约束（决定设计做法）

- 维护版 GPUI 没有逐元素 `backdrop-filter`，只有窗口级 `WindowBackgroundAppearance::Blurred`（Windows 为 DWM 合成模糊，见归档任务 `11-07-presenter-airy-glass/research/material-capabilities.md`）。
- 因此"玻璃"在本应用中的唯一真实来源是：**窗口整体透出模糊后的桌面**，各面板用半透明填充叠在其上。面板越不透明，玻璃感越弱；面板之间颜色越统一，越像一整块磨砂。
- 没有元素级模糊，就不能像网页那样"一张纸浮在场上"。正确的移植方式是：窗口 = 磨砂场，功能区 = 同色相、不同透明度的层，不画整窗纸、不画外圈线。

## Anthropic 暖橙的对比度事实

| 前景 | 背景 | 比值 | 结论 |
| --- | --- | --- | --- |
| `#FFFFFF` | `#D97757` | 3.12 | 白字压品牌橙不达 4.5，不可用于 14px 按钮文字 |
| `#FFFFFF` | `#CC785C` | 3.28 | 同上 |
| `#1F1712` | `#D97757` | 5.65 | 深色字压品牌橙可用，浅/深主题共用 |
| `#FFFFFF` | `#B5532F` | 4.95 | 若坚持白字，需加深到 `#B5532F` |
| `#B5532F` | `#FAF9F5` | 4.70 | 浅色主题橙色文字/链接 |
| `#E08A6A` | `#1C1A18` | 6.62 | 深色主题橙色文字 |
| `#E8A487` | `#1C1A18` | 8.34 | 深色主题强调文字 |
| `#6B645C` | `#F2ECE4` | 4.97 | 浅色次要文字压暖色洗底 |
| `#B8B0A6` | `#2A2622` | 7.01 | 深色次要文字压抬升层 |

结论：主按钮用品牌橙 `#D97757` 填充 + 近黑暖色字 `#1F1712`，浅深两套主题都成立，也最接近 Anthropic 的观感；橙色作为文字时，浅色用 `#B5532F`、深色用 `#E08A6A`。
