# 讲者界面暖橙毛玻璃样式重构

## 目标

当前"轻盈毛玻璃"只搬了色值，没有搬来轻盈感：窗口四周有一圈不搭的底场带和亮边，绿、紫、青三种色相同时出现，每个按钮都描边，工具组外又包了一层绿底。本任务保留"毛玻璃"材质与明/暗/跟随系统、毛玻璃开关这两个设置，把讲者界面改成**暖中性底 + 单一 Anthropic 式暖橙强调色**，按钮与面板改为现代的分层样式。

诊断与根因见 [research/diagnosis.md](research/diagnosis.md)，改前截图见 `research/before/`。

## 用户要求（原文要点）

1. 不要绿色，改用 Anthropic 的那种橙色，保持轻盈毛玻璃的样式。
2. 首页周围有一圈和整体配色不搭配的设计，打开 PDF 后也一样。
3. 按钮样式要优化，特别是"强行包裹了一层绿色"的观感。
4. 整体符合现代审美。

## 需求

- **R1 配色**：讲者界面只保留一个强调色相（暖橙，参考 `#D97757`）。中性色改为暖色系（象牙/石灰/暖炭），去掉绿色和紫色的语义角色。成功、警告、错误仍可用各自颜色，但只出现在状态文字或状态标记上，不作为按钮和面板底色。
- **R2 外圈**：首页、就绪、放映、设置、浏览各状态下，窗口内容一直铺到窗口边缘，不再出现缩进的底场带、整窗纸面描边或与内容色相不连贯的边缘。
- **R3 毛玻璃**：开启毛玻璃且系统允许时，窗口仍透出模糊桌面，各功能区呈现同色相、不同透明度的层次；关闭、窄窗、减少透明度或不支持时回退到同色相实色。现有回退判定和设置项语义不变。
- **R4 按钮**：去掉默认描边。按钮层级为：主操作（橙色实心）、次要/工具（中性半透明填充或幽灵按钮）、危险（文字或状态色，不画整圈红线）。同组按钮用分段控件（一个中性轨道 + 选中项抬升），不再用绿色外壳包裹。选中状态不能只靠颜色，也不能靠在标签前插入 `✓` 造成宽度跳动。
- **R5 面板**：顶栏、讲稿、当前页/下一页预览、底部控制栏使用一致的面板层与圆角；讲稿面板不再是紫底 + 黑色内框的双层色。
- **R6 一致性**：首页、工作台、设置、布局与导航菜单、开始模式菜单、页面浏览、跳页输入、裁剪对话、显示器设置、识别窗口全部使用同一套 token，不留旧绿/紫残色。
- **R7 设计源**：根 `DESIGN.md` 与 `theme.rs` 同步更新为新的设计语言，写明原生 GPUI 的材质做法（无逐元素模糊）和暗色变体，不再自称 "green for input and purple for output"。

## 约束

- 观众窗口只读 `AudienceProjectionSnapshot`，样式改动不得触及观众窗口像素、遮屏原色（黑/白）、PDF 与私有备注图像颜色。
- 不改设置文件 schema：`theme`、`glass_effect`、`ui_font_family`、`ui_font_size` 原样保留和生效，旧配置无需迁移。
- 保留现有 44px 最小交互目标、2px 焦点指示、键盘遍历顺序、拖动分隔条的命中范围、计时数字等宽。
- 不使用 Anthropic 的名称、标志、字标或专有字体文件，只借用色彩方向（design-atlas 品牌边界）。
- 不新增依赖，不改 GPUI 维护包（ADR-008/011）。

## 验收条件

- [ ] 浅色、深色两套主题下，讲者界面任一状态截图中，绿色和紫色色相（色相角约 90°–300° 之间、饱和度 >25% 的像素）只可能来自 PDF/备注图像本身。
- [ ] 首页和工作台截图四周不再有缩进的底场带和整窗描边；毛玻璃开启时窗口边缘与内部场底色相连续。
- [ ] 普通按钮默认无描边；主操作为橙色实心；黑屏/白屏与四个绘图工具以分段控件呈现，无彩色外壳；选中项有非颜色线索且切换选中时按钮宽度不变。
- [ ] 文字对比度 ≥4.5:1，焦点指示与选中标记对相邻颜色 ≥3:1；在毛玻璃最差合成背景（桌面纯黑与纯白）上用单元测试验证。原"按钮描边 ≥3:1"测试改为验证填充/焦点/选中标记，而非删除。
- [ ] 悬停、按下、禁用、选中、键盘焦点五种状态在浅深两主题各有可辨识样式。
- [ ] 毛玻璃开/关、窄窗、浅/深/跟随系统切换即时生效且不改变当前页、计时、批注、媒体和窗口角色；观众窗口内容区逐像素与改前一致。
- [ ] 默认字体与用户字体覆盖（如衬线字体）下各拍一组原生截图：首页、就绪工作台、放映工作台、设置、布局菜单；存入 `research/after/` 并与 `research/before/` 对照。
- [ ] `DESIGN.md` 更新；design-atlas `slop_check` 对 DESIGN.md 无 FAIL；`just ci` 通过。

## 不在范围内

- 自绘标题栏（替换 Windows 原生黑色标题栏）。它影响窗口拖动、系统按钮和多窗口角色，另开任务评估；本任务只记录其视觉影响。
- 布局结构调整（面板位置、比例、信息顺序）和新功能。
- 观众窗口、PDF 渲染、媒体播放。
