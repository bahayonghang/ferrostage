# 答疑跳转后返回准确讲述步骤

## 目标

讲者连续跳到多个附录或补充页后，可以一次返回跳出前的幻灯片和 overlay 步骤。

## 当前依据

`shell/page_browser.rs` 有数字、目录与缩略图的提交路径；`ferrostage-document/src/reload.rs` 的跨版本近似映射不适合承诺准确返回。Backspace 已用于上一页。

## 验收条件

- [ ] 第一次成功直接跳转保存提交前的页与步骤。连续跳转、顺序翻页或自动播放不覆盖；同页、错误输入、取消或仅预览不建立锚点。
- [ ] 底部仅在存在锚点时显示返回目标，可显式清除。Alt+Left 默认且可重绑，Backspace／Esc 保持既有功能；输入框或菜单获焦时不触发后台返回。
- [ ] 返回准确到步骤；到达并成功显示才消费。失败可重试，被新导航打断后迟到回执不能误清。其他途径准确回到原处后同样清除。遮罩下以底层公开目标就绪判定，保持遮罩。
- [ ] Stop／Resume／重置计时保留锚点；Home、重新打开、成功热重载和改变备注映射或裁切后清除。失败重载保留锚点。返回不改计时、画笔或暂停状态。
