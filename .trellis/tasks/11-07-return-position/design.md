# 答疑跳转后返回准确讲述步骤的实现边界

shell 文稿会话保存单个可选位置，来自直接跳转前已提交工作台，带代数和准确 PhysicalPage；overlay 步骤由当前 SlideMap 的精确映射展示，不使用热重载的近似映射，无需通用历史栈。通过公共导航提交判断首次成功，不从目录焦点或草稿读取。

## 已核对的入口与生命周期

数字、目录和缩略图都经 `shell/page_browser.rs::submit_browser` 到 `Shell::apply(Command::JumpTo)`。在 apply 成功且实际页变化时捕获首个离开位置；同页与错误输入不捕获。已有锚点时后续直接跳转、顺序导航和自动播放都不覆盖。

返回复用精确 JumpTo，保留锚点直到对应目标显示成功。Presenting 使用投影状态任务校验过来源窗口和 PlaybackIdentity 的 Settled；Ready 使用讲者当前页实际绘制结果。导航打断后拒绝迟到结果。其他导航准确回到原处且显示完成同样消费。遮屏下用匹配代数、页、裁切、优先级和当前目标尺寸的底层公开帧就绪条件判定，保留遮屏，不伪造可见绘制。

Stop、Resume 与重置计时保留锚点；Home、重新打开、成功热重载和实际改变备注映射/裁切后清除。失败重载和失败裁切保留。不得因某一帧缺失或开始新导航就清除锚点。

## 交互与设置

底部有锚点时才显示准确返回目标和清除动作。Alt+Left 作为默认值，经既有设置解析、保存、冲突诊断及 GPUI 绑定路径支持重绑。保留 Backspace 与 Escape。数字输入、菜单和模态拥有焦点时先消费输入，不能后台返回。复用 DESIGN.md 和既有焦点/延迟协调分发规则。

## 集成与回退

先交付投影状态的公开身份，再关联正确窗口和请求。仅增加讲者会话状态，不向观众增加备注/锚点。撤回返回控件、可选设置动作和会话状态即可恢复原导航；无锚点的现有会话行为保持一致。

## 验证边界

用带 overlay 的 A 步骤 2→B→C→A 实测，并覆盖失败可重试、旧窗口/旧代/迟到绘制、遮屏返回、Stop/Resume、成功与失败重载、输入框/菜单焦点及按键重绑。普通原生窗口检查返回目标和计时/暂停/画笔保留，不扩展无关窗口矩阵。
